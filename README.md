Benchwork Physics Labs is a set of 49 interactive virtual labs for an algebra-based physics course. Each one works like a real practical, not just a simulation.

In every lab, students:

answer pre-lab questions and make a prediction
follow a step-by-step procedure
read the instruments themselves (scales, meters, verniers, counters)
repeat trials and fill in a results table
plot a graph with a line of best fit and work out the slope
answer analysis questions and write a conclusion

Many labs end with a “sealed” unknown, such as a mystery mass, an unknown work function or a hidden half-life, that students can only find from their own data.

Topics: Mechanics (17 labs) · Fluids (2) · Thermal Physics (6) · Oscillations & Waves (6) · Electricity & Magnetism (8) · Optics (5) · Modern Physics (5).

It runs in any modern browser on computers, tablets and phones, with no sign-in. Each student’s progress is saved in their own browser.
